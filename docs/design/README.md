# Design mockups
Static HTML exports of every screen (dark and light). `index.html` shows them all; `canvas.json` lists titles and sizes. Files named Fd, Bd, Hi, Ix, Pr, So, Bk, Sm, Dm, Ds, Dp, Dg, P1-P12 are dark; Main, B, D, E, LHi..LDg, LP1-LP12 are light. A missing support.js is harmless: the files render as plain HTML.
