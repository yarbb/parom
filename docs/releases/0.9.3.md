**New**
- **Parom for Linux** (x86-64, experimental): `Parom_0.9.3_amd64.AppImage`. Make it executable and run it. Everything works as on Windows: SFTP, FTP and FTPS, sync, the GitHub tab, updates. Saved passwords go to the Secret Service (GNOME Keyring, KWallet). If something does not work on your distribution, please [report it](https://github.com/yarbb/parom/issues/new).

**Also new since 0.9.1** (from 0.9.2, on Windows and Linux)
- **Resolve pull conflicts in Parom**, like GitHub Desktop. When you and the remote changed the same lines, a window lists the files: keep your version, take theirs, or open the file in your editor and fix the marked places. Then continue, or abort and everything is back as it was before the pull.
- **Errors you can read**: long messages open in their own window that stays until you close it, with a Copy button.
- **File names first in Changes**, the folder after them in grey; Preferences → Repositories brings whole paths back.
- **New issues show up at once** at the top of the list, with the counts updated.
