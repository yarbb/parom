**New**
- **Parom for Linux** (x86-64, experimental): `Parom_0.9.3_amd64.AppImage`. Make it executable and run it. Everything works as on Windows: SFTP, FTP and FTPS, sync, the GitHub tab, updates. Saved passwords go to the Secret Service (GNOME Keyring, KWallet). If something does not work on your distribution, please [report it](https://github.com/yarbb/parom/issues/new).

Nothing changes on Windows in this version.
