**New**
- **Resolve pull conflicts in Parom**, like GitHub Desktop. When you and the remote changed the same lines, the pull no longer gives up: a window lists the files. For each one, keep your version, take theirs, or open it in your editor and fix the marked places; the list notices saved edits by itself. Then continue (the merge is committed, or the rebase goes on), or abort and everything is back as it was before the pull.
- **Errors you can read**: long messages open in their own window that stays until you close it, with the text selectable and a Copy button. Short ones stay in the toolbar until closed; click one to see it whole.
- **File names first in Changes**: each file shows its name, then its folder in grey, so long paths are no longer cut off. Preferences → Repositories brings whole paths back.
- **New issues show up at once**: an issue created in Parom appears at the top of the list, opens, and the counts go up right away, without waiting for GitHub's own lists to catch up.

Already on 0.9.0 or 0.9.1? Parom offers this update by itself; it takes one click.
