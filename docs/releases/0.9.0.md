First public beta of Parom: an SFTP/FTP client on the FileZilla engine, with a GitHub tab and version-aware server sync.

**Files**
- Dual-pane file manager for SFTP, FTP and FTPS, with a Site Manager, saved passwords in the system's credential store and automatic reconnect.
- Drag and drop between the panes, from Explorer and out to Explorer; simultaneous transfers; edit server files in place.
- Synchronized browsing (Ctrl+Y), folders that match on both sides tinted grey, colour labels for folders.

**Sync**
- A small marker file on the server records which commit is deployed, so Parom knows when the server is behind, ahead or edited by hand.
- Backups of everything a sync overwrites, with restore; "Back up now" without syncing.

**GitHub**
- Changes (commit, discard, ignore), History, Issues and Pull requests in the app, like GitHub Desktop.
- Commits with "Fixes #N" close their issue once a sync deploys them.

**And**
- Dark and light themes with accent colours, English and Russian.
- Optional Discord Rich Presence (off by default, never shows server addresses).
- Updates from here, installed when you choose.

Windows only for now; a Linux AppImage follows. The installer is not code-signed yet: Windows SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**.
