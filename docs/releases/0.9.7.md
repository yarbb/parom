**Fixed**
- **No error window after leaving the GitHub tab open**: the Issues and Pull requests lists refresh in the background, and when GitHub did not answer (offline, timed out) the error window popped up. Now the last list stays, with a short note that it could not refresh; it tries again by itself.
- **Windows open on top of the window they came from**: *Check for updates* in Preferences showed its result behind Preferences.
- **A folder that is a git repository of its own** (a library cloned into the project) no longer breaks commits with "invalid path". Changes lists it greyed out with a note on what to do; it is never committed or discarded, and right-click can add it to .gitignore.

**Also new since 0.9.5** (from 0.9.6)
- History menu like GitHub Desktop: amend, reset, checkout, move, revert, branch, tag, cherry-pick.
- A site's folder can be a folder inside its repository, and Parom notices when the site's files move inside it.
- One error window for all errors, with the recent ones in the status bar.
- Automatic updates, off by default (Preferences → Updates).
- Huge Changes lists no longer freeze the window; moved files show as renames.
