**New**
- **Files that still need uploading are highlighted** in the local file list: changed files in amber, new ones in green, and folders holding them get a dot. Both kinds count: changes not committed yet, and files committed since the last sync that are not on the server yet (the tooltip says which). Preferences → File lists can turn it off.
- **Show in Files tab**: right-click a file in Changes to open its folder in the Files tab with the file selected (for a deleted file, the nearest folder that is still there).

**Also new since 0.9.6** (from 0.9.7)
- No error window when the GitHub tab could not refresh in the background: the last list stays with a short note.
- Windows open on top of the window they came from (*Check for updates* in Preferences).
- A folder that is a git repository of its own no longer breaks commits; Changes lists it greyed out.
