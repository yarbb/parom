**New**
- **Folder preview under each list**, like FileZilla's second list: click a folder (once) and a panel below shows what is inside, without opening it. Double-click a folder there to open it above, or a file to transfer it. On the server side it uses listings Parom already has and lists a folder at most once, so the server does not get extra requests per click. Drag the bar above it to resize; turn each side off with × or in View, or in Preferences → File lists.
- **Ignore files from the file lists**: right-click files or folders inside a repository (on your computer, or on the server of a site linked to one) and choose *Add to .gitignore*, *Add \*.ext to .gitignore* or *Never upload or overwrite (.parom-ignore)*. The file is created if it is missing, and a line that is already there is not added again.
- **Drop files from Explorer onto the local list**: they are copied into the folder it shows. If a name is already taken, choose Replace, Keep both or Skip.

**Better**
- Dragging server files out of the window no longer shows their download in the queue: the files are fetched quietly in the background. Dropping them on the local list right away uses those files instead of downloading them again.

Also new since 0.9.2: **Parom for Linux** (x86-64, experimental): `Parom_0.9.4_amd64.AppImage`.
