**New**
- **Your own keyboard shortcuts**: Preferences → Keyboard shortcuts. Click a command, press new keys; clear one, go back to the default, or reset everything. Shortcuts now work on any keyboard layout (Ctrl+S on the Russian layout too).
- **Folder suggestions in the path bars**, like Explorer's address bar, on your computer and on the server. Tab or → takes a suggestion. On the server they come from folders already listed, so typing never floods it with requests.
- **@-mentions**: type "@" in a comment or a new issue to pick someone from the thread or the repository.
- **Issue lists refresh by themselves**: when you come back to the page or the window, and every 90 seconds while it is open.
- **Pull without merge commits**: when both sides have new commits, your unpushed commits are put on top of the new ones (rebase). History stays one line. Preferences → Repositories can switch back to merge commits.

Already on 0.9.0? Parom offers this update by itself; it takes one click.
