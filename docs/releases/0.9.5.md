**Fixed**
- **No more freeze at start** when a mapped network drive is slow to answer: Parom looked at every drive letter on the window's own thread, so the window stopped responding (and turned white) for a few seconds while the local list stayed empty. Drives are now checked in the background, all at once, and the local list opens its folder without waiting for them.
- **What's new is readable**: this window shows the notes formatted (bold, lists, code) instead of raw Markdown.

**Also new since 0.9.3** (from 0.9.4)
- **Folder preview under each list**, like FileZilla's second list: click a folder once and a panel below shows what is inside. Turn each side off with × or in View, or in Preferences → File lists.
- **Ignore files from the file lists**: right-click → *Add to .gitignore*, *Add \*.ext to .gitignore* or *Never upload or overwrite (.parom-ignore)*.
- **Drop files from Explorer onto the local list** to copy them into its folder (Replace, Keep both or Skip when a name is taken).
- Dragging server files out of the window no longer shows their download in the queue.
